# iDonat Robot — boshlang‘ich bot

Bu Telegram botning boshlang‘ich demo versiyasi. Unda bo‘limlar va javoblar mavjud.

## Ishga tushirish
1. Python 3.10 yoki yangiroq versiya kerak.
2. `pip install -r requirements.txt`
3. `BOT_TOKEN` nomli environment variable yarating.
4. `python main.py`

## Muhim
- Bot tokenini GitHub'ga yoki chatga joylamang.
- Railway kabi hostingda `BOT_TOKEN` ni Variables/Environment Variables bo‘limiga kiriting.
- Hozircha to‘lov, buyurtmalar bazasi va avtomatik yetkazib berish ulanmagan.
- PUBG UC faqat rasmiy/vakolatli yetkazib beruvchi integratsiyasi bilan avtomatik berilishi mumkin.
- To‘lovlarni haqiqiy provayder sozlanib, sinovdan o‘tmaguncha qabul qilmang.
